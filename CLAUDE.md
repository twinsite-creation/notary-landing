# Правила для цього репо

- НІКОЛИ не виконуй `git commit`, `git push`, `git add`, `git reset`, `git checkout` чи інші git-команди, що змінюють репо. Коміти робить Надя вручну.
- Тільки редагуй файли. Після кожного етапу коротко перелічи, які файли і що змінено, щоб я могла перевірити й закомітити.
- План робіт — у PLAN.md. Дані демо-нотаріуса — у DATA.md.
- Стек: чистий HTML/CSS/vanilla JS, без бібліотек і збирачів.
- Мова інтерфейсу — українська (index.html) і англійська (index-en.html).
